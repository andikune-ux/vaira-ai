# Grup Obrolan Privat

Grup bersifat privat. Hanya member aktif yang dapat melihat riwayat, daftar member, dan profil grup. Pembuatan grup menjadikan pembuat sebagai admin tunggal. Administrator dapat mengubah nama, mengundang, mengeluarkan member, membuat tautan undangan baru, atau menyerahkan admin kepada member aktif lain.

Jika admin keluar dan masih ada member, admin berpindah kepada member yang terakhir bergabung. Jika admin adalah satu-satunya member, grup ditandai terhapus tanpa menghapus riwayat fisik. Grup yang dibekukan oleh Administrator Vaira tetap dapat dibaca, tetapi tidak dapat menerima pesan, undangan, atau member baru. Setiap akun dapat memiliki paling banyak 10 keanggotaan grup aktif.
